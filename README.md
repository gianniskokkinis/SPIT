# SPIT 📚

SPIT is an experimental Android application designed to help students get real-time updates on the status of their courses.

## 🧠 Idea

The idea of the app was born out of the need for immediate information on:
- If the lesson has started or is delayed.
- If it is on break or completed.
- What chapter the professor is in.
- Additional announcements that are not usually published on official university platforms.

## 📱 Technologies
- **Android Studio**
- **Java**
- **MySQL**
- **JDBC Driver** for interface with database

## 🔧 Features

- Real time information on the progress of the course
- Students can update status updates or short announcements

## 🚧 Project Status

The application is at **experimental/incomplete stage**. Although it has basic functionality, it is not fully completed as a production-ready application. Nevertheless, the code is available for study, experimentation and future development.
